# Лабораторная работа № 5 — «Движение агента в стохастической среде»

Репозиторий: https://github.com/kostiashkaaa/Laboratory-5_java

Агент в полностью наблюдаемой, но недетерминированной среде (марковский процесс принятия решений, MDP).
Выбранное направление выполняется с вероятностью 0.8, с вероятностью по 0.1 агента сносит ветром
перпендикулярно движению. Агент ищет стратегию с максимальной ожидаемой полезностью двумя
алгоритмами: итерацией по стратегиям (основной, как в задании) и итерацией по значениям (для сверки).
Найденную стратегию он затем исполняет, а движение показывается на экране.

## Запуск

Нужна только JDK 17+ (проект собирается без Maven/Gradle).

Готовый билд:

```bash
java -jar dist/laba5.jar
```

```bash
java -jar dist/laba5.jar --console --risk-demo
```

Сборка (компиляция с `-Xlint -Werror`, самопроверка, упаковка в `dist/laba5.jar`):

```bash
./build.sh
```

Запуск из исходников:

```bash
./run.sh
```

```bash
./run.sh console --reward -0.3 --gamma 0.9 --p 0.8
```

```bash
./run.sh test
```

```bash
./run.sh snapshot docs/visualization.png
```

В IntelliJ IDEA откройте папку `laba5` (JDK `homebrew-21`). Готовые конфигурации запуска:
**Laba5 GUI**, **Laba5 Console**, **Laba5 SelfTest**. Jar собирается через Build → Build Artifacts → `laba5:jar`.

### Опции консоли

| Опция | Смысл | По умолчанию |
|---|---|---|
| `--reward R` | награда R(s) обычной клетки | −0.04 |
| `--gamma G` | коэффициент дисконтирования γ ∈ (0; 1] | 1 |
| `--p P` | вероятность движения в выбранном направлении | 0.8 |
| `--algo pi\|vi\|both` | алгоритм | both |
| `--episodes N` | эпизодов для проверки Монте-Карло | 10000 |
| `--max-steps N` | лимит шагов в эпизоде | 1000 |
| `--seed S` | зерно случайных чисел (π₀ и эпизоды) | 42 |
| `--risk-demo` | стратегии при разных R(s) | — |

## Координаты

Клетки записываются как в уравнении Беллмана из задания: **(столбец, строка)**, клетка (1,1) находится в левом нижнем углу.
В тексте задания клетки «(3, 4) = +1» и «(2, 4) = −1» даны в порядке (строка, столбец). В программе это (4,3) и (4,2).

## Результат для мира из задания (R(s) = −0.04, γ = 1)

```
Полезности U(s):                       Оптимальная стратегия π*(s):
 3 │ 0.812   0.868   0.918    [+1]      3 │   →       →       →      [+1]
 2 │ 0.762    ###    0.660    [-1]      2 │   ↑      ###      ↑      [-1]
 1 │ 0.705   0.655   0.611   0.388      1 │   ↑       ←       ←       ←
       1       2       3       4              1       2       3       4
```

Значения и стрелки совпадают с таблицей и рисунком задания. Выбор действия в (1,1) по уравнению из задания:

```
Up    0.8·U(1,2) + 0.1·U(1,1) + 0.1·U(2,1) = 0.7453  ◀ выбор
Left  0.9·U(1,1) + 0.1·U(1,2) = 0.7109
Down  0.9·U(1,1) + 0.1·U(2,1) = 0.7003
Right 0.8·U(2,1) + 0.1·U(1,2) + 0.1·U(1,1) = 0.6709
U(1,1) = -0.04 + 1·0.7453 = 0.7053
```

> В задании строка `Right` уравнения состояния (1,1) повторяет строку `Up` (опечатка).
> Верная запись: 0.8·U(2,1) + 0.1·U(1,2) + 0.1·U(1,1), и программа считает именно её.

## Соответствие требованиям

| Требование задания | Где реализовано |
|---|---|
| Среда полностью наблюдаема, агент знает свою клетку | `StochasticEnvironment.position()` |
| Стохастическое движение 0.8 / 0.1 / 0.1 (рис. 1) | `TransitionModel.transitions`, `sampleDirection` |
| R(s) = −0.04, выходы +1 / −1, мир 4×3, стена, старт (1,1) | `GridWorld.classic` |
| Полезность — сумма наград, «полезность ограничена» | `StochasticEnvironment` (Σ R, Σ γᵗR); проверка ограниченности в `Mdp` |
| U(s) = R(s) + γ·max Σ T(s,a,s')·U(s') | `ValueIteration`, `Mdp.qValue` |
| Оценка стратегии U_{i+1}(s) = R(s) + γ·Σ T(s,πᵢ(s),s')·Uᵢ(s') | `PolicyEvaluator.iterative` (+ точное решение СЛАУ `exact`) |
| Улучшение стратегии πᵢ₊₁ | `PolicyIteration.solve` |
| Класс агента: принятие решения о направлении | `MdpAgent.decideDirection` |
| Класс агента: перемещение | `MdpAgent.move` |
| Класс агента: расчёт полезности стратегии | `MdpAgent.evaluatePolicyUtility`, `policyUtility` |
| Класс среды | `GridWorld` + `TransitionModel` + `StochasticEnvironment` |
| Пример выбора действия Up/Left/Down/Right | `TextRenderer.decision` (консоль и панель «Решение агента» в GUI) |
| Равновесие риска и вознаграждения от R(s) | пресеты в GUI, `--risk-demo` |
| Поиск оптимального пути и визуализация движения | `MainFrame`, `GridPanel` |

## Графический интерфейс

- **Мир**: ширина и высота от 2 до 10. При смене размера и по кнопке «Сгенерировать мир» строится новый случайный мир того же вида, что в задании: старт (1,1), +1 в правом верхнем углу, −1 под ним, стены ≈ 12 % клеток, ещё одна ловушка −1 на каждые 20 клеток. Генератор (`WorldGenerator`) принимает мир, только если из старта достижим +1 и из каждой клетки достижим какой-нибудь выход. Кнопка «Мир из задания» возвращает 4×3, редактор меняет клетки мышью. ЛКМ переключает клетку по кругу
  пусто → стена → +1 → −1 → пусто, ПКМ или Shift+щелчок переносит старт.
- **Параметры MDP**: R(s), γ, P(вперёд), готовые примеры (−0.04, −2, −0.3, −0.01, 0, +0.5 при γ = 0.9).
  Стратегия пересчитывается сразу после изменения.
- **Алгоритм**: итерация по стратегиям или по значениям, seed. Ползунок «Итерация» показывает Uᵢ и πᵢ на любом шаге алгоритма.
- **Агент**: «Шаг», «Пуск/Пауза» (анимация), «Новый эпизод».
  Путь агента рисуется линией, снос ветром отмечается пунктирным кольцом и в строке состояния.
- **Решение агента**: уравнение выбора действия в текущей клетке, как в примере из задания.

Снимки экрана лежат в `docs/`.

## Проверки и аудит

`./run.sh test` прогоняет 11 131 проверку в 21 группе:

- полезности и стратегия совпадают с таблицей и рисунком задания у **обоих** алгоритмов (погрешность < 0.0006);
- алгоритмы дают одинаковый результат на 60 случайных мирах до 10×10 с разными R, γ и P;
- итерация по стратегиям при 30 разных начальных π₀ сходится к одной и той же стратегии;
- найденные U удовлетворяют уравнению Беллмана (погрешность < 1e-8), а π(s) достигает максимума в каждой клетке;
- точная оценка стратегии (метод Гаусса) совпадает с итеративной; для «зацикленной» стратегии при γ = 1 система определена как вырожденная;
- Монте-Карло: средняя сумма наград по 50 000 эпизодам совпадает с U(1,1) = 0.705 (и с U(s) других клеток) в пределах 4σ;
- частоты сноса ветром равны 0.8 / 0.1 / 0.1, назад агента не сносит;
- пороги риска из учебника Рассела и Норвига (рис. 17.2): при R = −2 агент бежит к любому выходу, при R = −0.3
  идёт коротким путём с риском, при R = −0.01 упирается в стену, лишь бы не рисковать, при R > 0 (γ < 1) избегает выходов;
- генератор строит корректные миры всех размеров от 2×2 до 10×10 (выход достижим, стратегия находится при γ = 1);
- отклоняются некорректные входные данные: γ ∉ (0;1], P ∉ [0;1], R > 0 при γ = 1, область без выхода, мир без выходов.

- компиляция с `-Xlint:all -Werror` без предупреждений.
